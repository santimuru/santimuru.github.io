# Santiago Martinez — Personal Portfolio

Personal portfolio and CV site, available at [santimuru.github.io](https://santimuru.github.io).

## About

Data Analyst with 6+ years of experience across telecom, e-commerce and consulting. Currently based in Tokyo, working as Lead BI Analyst at Montecable.

## Stack

- HTML / CSS / Vanilla JS
- Multilingual (EN / ES / JA) via a custom i18n system using `data-key` attributes
- Downloadable CVs in 3 languages (PDF)
- Hosted on GitHub Pages

## Structure

```
index.html          # Main site
css/styles.css      # Base styles (Bootstrap 5 + custom)
js/translations.js  # i18n translations + language switching logic
js/scripts.js       # Scroll spy
assets/
  img/              # Profile photo
  cv/               # CV files (HTML source + PDF)
```
